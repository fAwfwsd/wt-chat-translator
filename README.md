# 战争雷霆 · 聊天翻译

游戏里别人打的一串英文俄文，实时翻成中文贴在屏幕上；你要回话，打中文回车，自动翻成英文塞进游戏聊天框。

## 它怎么干活的

游戏跑起来后，本机 `127.0.0.1:8111` 会开一个**只读**接口，其中：

```
GET /gamechat?lastId=N
[{ "id": 5, "msg": "enemy at B4", "sender": "Ivan", "enemy": false, "mode": "友军", "time": 41 }]
```

所以不截图、不做 OCR，直接读文本 —— 一个字母都不会认错。

翻译走免费接口（Google / 有道 / MyMemory 自动兜底），不填任何 key 就能用。填了大模型 key 质量会好很多。

## 启动

双击 `启动.bat`（或 `start.bat`）。

- 第一次启动会自动生成 `config.json`
- 想看界面长什么样、游戏又没开：`python main.py --demo`

## 快捷键

| 键 | 作用 |
|---|---|
| `F8` | 显示 / 隐藏悬浮窗 |
| `F9` | 进入打字模式（可以直接输入） |
| `F10` | 清空记录 |

**改键**：点 ⚙ 打开设置 → 快捷键那一行，点一下框直接按你要的键。
每个键右边会实时显示 `✓ 生效` 或 `✗ 被占用`。

> ⚠️ 如果显示 `✗ 被占用`，说明那个键被别的软件抢了（加速器、输入法、显卡驱动都爱抢 F 键）。
> 换个键就行。实测 F6/F7/F5/F4 一般都能用；F9/F10/F12 经常被占。

## 界面上怎么用

- **看**：每条消息上面是原文（灰色），下面是译文（青色）。敌军频道的人名是红的。
- **回**：点输入框（或按 F9）直接打字 → 回车 → 自动翻译并切回游戏发出去。
- **点窗口不会抢游戏焦点**：平时窗口是"不激活"状态，点它、拖它都不影响游戏里按 Enter。
  只有点输入框或按 F9 时才会临时接管键盘，发完自动还回去。
- 底部状态灯：
  - 🟢 **对局中**
  - 🟡 **对局已结束**（结算界面发不了聊天）
  - ⚪ **机库里**（进对局才有聊天）
  - 🔴 **没连上游戏**
- 右键悬浮窗：复制原文/译文、隐藏原文、清空、打开配置。

## 设置面板

点标题栏的 ⚙：

| 项 | 说明 |
|---|---|
| 窗口透明 | 0.25~1.0，整个窗口的不透明度 |
| 文字透明 | 0~1.0，**只影响文字**，和窗口透明度完全独立 |
| 字号 | 8~20 |
| 刷新间隔 | 拉聊天记录的频率 |
| 同时显示原文 | 关掉就只看译文 |
| 中文消息也翻一遍 | 默认关（队友说中文就不用翻） |
| 游戏黑话词典 | gg / n1 / cap / arty 这类直接给中文 |
| 自动发进游戏 | 关掉就只复制到剪贴板 |
| 翻译引擎 | Google / 有道 / MyMemory，可以勾选启用哪些 |
| 逐个测试 | 挨个请求每个引擎，显示耗时和译文，一眼看出谁能用 |
| 大模型 | 填 base_url + 密钥 + 模型名，填了就默认优先用 |

**密钥是加密存的**：用 Windows DPAPI 加密后写入 `config.json`，只有本机当前 Windows 用户能解开。
拷到别的电脑、或者别人打开文件，看到的都是 `dpapi:AQAAANCM...` 这种密文。

### 接大模型（可选，质量好很多）

默认配置：

```json
"llm": {
  "enabled": true,
  "base_url": "https://api.deepseek.com/v1",
  "api_key": "",
  "model": "deepseek-flash"
}
```

把 `api_key` 填进设置面板就行（不用改 JSON）。任何 OpenAI 兼容接口都能用：
DeepSeek 官方、通义、Kimi、本地 ollama 都行。

填完点「逐个测试」验证，通了会显示 `✓ 0.6s` 加译文。

**免费引擎 vs 大模型的差别**（实测）：

| 原文 | 免费引擎 | 大模型 |
|---|---|---|
| spawn camping is cancer | 产卵露营是癌症 | 在重生点蹲守真是**毒瘤** |
| arty on the hill | 山上有艺术气息 | 山上有**火炮** |
| anyone cover me while I cap bravo? | 当我为 Bravo 盖帽时有人掩护我吗 | 有人**掩护我占B点**吗 |

## 常见问题

**状态灯是红的 / 显示"没连上游戏"**
游戏没开，或者本地接口没起来。只在**进入对局后**才有聊天数据。

**按 Enter 打不开聊天框**
1. 先看状态灯——如果是黄灯，说明这局已经打完了，结算界面发不了
2. 检查输入法：中文输入法激活时，回车会被输入法吞掉。按 `Shift` 切英文再试
3. 别在悬浮窗的输入框里留着光标

**悬浮窗被游戏盖住**
游戏用「无边框窗口」模式（`fullscreenwindowed`）。独占全屏下任何置顶窗口都显示不出来。

**翻译一直失败**
点设置里的「逐个测试」，它会告诉你哪个引擎挂了、为什么挂。

**改了键位没反应**
看设置里那个键右边是 `✓` 还是 `✗`。`✗` 就是被别的程序占了，换一个。

## 自动检查更新

程序启动后会（延迟 5 秒）在后台访问 GitHub Releases，对比本地版本号。有新版时状态栏提示「发现新版本 x.y.z」，右键悬浮窗有「下载新版本」直达下载页。

要启用，在 `config.json` 里填你的仓库：

```json
"update_check": true,
"update_repo": "你的名字/仓库名"
```

- `update_repo` 留空 = 不检查（默认就是空）
- 检查失败（断网 / 仓库没有 Release / 被限流）会静默，不影响使用；右键菜单能看详情
- 手动检查：右键悬浮窗 → 「检查更新」

> 版本号写在 `wtchat/__init__.py` 的 `__version__`，发新版时记得一起改，Tag 用 `v1.2.3` 这种格式。

## 文件结构

```
wt-chat-translator/
├── 启动.bat / start.bat   双击启动
├── main.py                入口
├── config.json            自动生成（密钥加密存）
└── wtchat/
    ├── api.py             读游戏本地接口、清洗富文本标签、判断对局状态
    ├── translate.py       翻译引擎链 + 黑话词典 + 缓存 + 译后修正
    ├── ui.py              悬浮窗（双窗口：背板 + 文字）、轮询、渲染、打字模式
    ├── settings.py        设置面板
    ├── winput.py          剪贴板 / 模拟按键 / 找游戏窗口
    ├── hotkeys.py         全局热键（带注册状态检测）
    ├── secret.py          DPAPI 密钥加密
    ├── updater.py         GitHub 更新检查
    └── config.py          配置读写
```

## 几句实话

- 8111 是**游戏自己开的只读接口**，本工具只读不写，不会往游戏里注入任何东西。
- 回话靠模拟按键（跟你在键盘上敲一样），理论上任何反作弊都可能看不惯这类操作。
  怕的话就把「自动发进游戏」关掉，只复制到剪贴板，手动 `Ctrl+V`。
- 免费翻译接口没有 SLA，哪天挂了就换一个，`translate.py` 里加个函数就行。
- 只支持 Windows。
